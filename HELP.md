# 🚀 API Reconecta - Transforma API

Este projeto é o Back-end da plataforma Reconecta, focado em ajudar na ODS 4 (Educação de Qualidade) e ODS 10 (Redução das Desigualdades) através de cursos gratuitos.

## 📌 Rotas Planejadas para a API (Sprint 1)

### 👤 Usuários (/usuarios)
* Criar um novo usuário (aluno ou mentor) na plataforma.
* Listar as pessoas cadastradas.

### 📚 Cursos (/cursos)
* Cadastrar um novo curso ou oficina digital.
* Listar todas as aulas e cursos disponíveis.

### 🤝 Inscrições (/inscricoes)
* Inscrever um aluno em um dos cursos disponíveis.
